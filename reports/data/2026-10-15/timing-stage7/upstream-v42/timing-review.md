# Updated official v42 timing review

Measured with upstream 302f0cf's default ABC buffering/sizing and unchanged STA constraints: 302.689920 MHz, area 35006.82786 um². This is not yet the user’s 400 MHz target.

## Evidence and identity

`path-origin.json` and `path-preabc.json` were generated by `scripts/area_v2/path_origin.py --registers` against this exact frozen `upstream-v42` design. The older baseline pre-ABC dump was not reused: its prepared-JSON hash and byte count differ. No RTL or synthesis framework was changed by this review.

## Actual critical path

The first path starts at integer IQ bank 0, row 2 ROB owner/rid bit 1 (`core.select_owner[0][13]`, packed `core.queue[2][178]`) and ends at `core.mdu.out_result_q[30]`. The other four reported paths end at `mul_result_q[0][30]`, `out_result_q[31]`, `out_result_q[29]`, and `mul_result_q[0][29]`. This is the original unpipelined multiplier path, not the memory prepared-address path of the later stage7 experiment.

The path has 109 output arcs including the starting flop. IQ selection produces index[1] at 0.5504 ns and index[0] at 0.6682 ns. The selected operand a[5] exits the IQ read slice at 0.8589 ns. The remaining multiplier/correction/output logic reaches the result-register D input at about 3.249 ns; the measured minimum period is 3.3037109375 ns including uncertainty and setup.

## Remaining load

The largest delay on these five paths is only 0.0715 ns (IQ select index[0], fanout 24, 9.7037 fF). Select index[1] has fanout 21, 8.2701 fF, delay 0.0599 ns. There are no remaining 0.5–1 ns fanout stages on the reported critical paths. The old massive fanout collapse has therefore been substantially repaired by upstream buffering/sizing.

## Implication

The already-built two-stage multiplier is the right next candidate: it moves 16x16 partial products to an existing new pipeline register and puts carry-save reduction plus prefix final addition in the second stage. The prefix effective-address and ALU additions still address a different demonstrated stage7 bottleneck, but cannot alone fix this v42 multiplier path. Wait for the updated-flow prefix-v3 result before adding more distribution trees. If area exceeds 36000 um², first compare optional COMMIT_TREE and noncritical MDU word-control trees; avoid shrinking IQ/ROB prematurely because the original IPC margin above 1.0985 is about 1.4%.
