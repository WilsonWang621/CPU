# 综合展开诊断与验收状态

当前综合输入为冻结 RTL 经 sv2v 转换的 Verilog-2005。工具使用固定版本
Yosys 0.69+75、Slang、ABC 和 ASAP7 RVT TT；旧 Yosys 0.33 已停止使用。
缓存、队列、PRF、预测器均计入片上逻辑，外部 RAM 不在综合输入中。

## 已复现并修复的展开问题

| 问题 | 修复与证据 |
| --- | --- |
| 多维 packed 位图的动态小切片变为整平面移位网络 | 显式窄行/窄字读取；D-cache 位级展开 4,240,977→1,646,631 单元，I-cache 1,217,687→600,499；见 [缓存诊断](cache_bit_expansion.md) |
| 只读 valid/done 等字段却选择完整记录 | ROB、等待者采用字段列；Load issued 与 Store completed 也通过单独位列读取 |
| 环形扫描产生重复的动态记录选择器 | 固定物理行读取，比较有界年龄；保留逐字节最近 Store 选择及重放语义 |
| 对结构数组动态部分写入造成全数组读改写 | 核心执行、写回、分派产生有限事件，由每个固定条目更新 |
| 多维 cache 数据阵列推断出少量超宽字 | D-cache 为真实 32 位字 RAM；I-cache 为整行 RAM，分别保留三个与两个读端口 |
| 预测表复位/写法增加大量写端口或拖慢仿真 | 窄字 RAM 配合复位有效位；四路训练别名按程序序折叠，复位语义逐周期验证 |
| 每个 ROB 保存完整 RAT 副本 | 组合重建存活映射，一沿恢复；旧检查点仅作仿真参考，见 [恢复验证](data/core_integrated_rat_mul.json) |
| 小 RAS 配置仍保留 16 项存储反馈 | 在各个 RAS 存储边界明确保留配置深度以内的位，证明高位为零的可达状态不变量 |
| IQ/LQ/CSB 的动态完整记录更新形成整银行选择网络 | 窄控制工作列配合有界分配事件；core coarse mux 位数 1,024,737→674,488，见 [记录](data/core_queue_events.json) |
| 选最老记录的线性比较链 | 保持稳定优先级的平衡树；16 core、76 LSU、六项性能回归事件计数不变，见 [回归](data/core_balanced_directed.json) |
| 位级 `opt_merge` 反复扫描全图，ABC `dc2` 又陷入长耗时 | 使用拓扑结构哈希及直接映射，保留全部连接、映射和无锁存检查；见 [ABC 分阶段诊断](abc_stage_audit.md) |

独立的小选择器复现先转换为 Verilog，再使用相同 Yosys 路径。32 组配置的
中间单元数从 172,524 降至 5,168，完整结构检查从约 10.17 秒降至 0.27 秒；
所有位图、合法索引的组合等价证明通过。见
[证明及原始统计](data/packed_plane_select.json)。这些数字描述中间展开，不能当作最终映射面积。

## 全核结果的边界

旧的精简全核尝试在 600 秒上限内未完成，产生约 3.8 GB 的未优化 RTLIL、
8,806,205 个临时单元。后续仅调整清理顺序的实验仍超时，证明不能只靠延长
等待或更换命令顺序解决。以上 RTL 修复针对实际宽度及选择网络来源。

已完成一个冻结全核版本的 ASAP7 映射，严格映射、连接和无锁存检查通过。
其面积 **213,372.876237**，超过 40,000；有 2,422,843 个映射单元。
从 `techmapped.il` 恢复到映射检查完成耗时 371.16 秒，**不是端到端综合耗时**。
该版本 core SHA 为 `352a51ee…`，早于 IQ/LQ/CSB 事件写入、平衡选择树和年龄
简化，不能把它的面积标注为最新 RTL 的结果。见 [冻结输入及完整数据](data/full_mapping_planes.json)。

该网表的 OpenSTA 在 `check_setup` 阶段触及 600 秒上限，尚未产生完整
setup/hold 结果，整核时序为未知。ABC 的门级估算延迟约 56.38 ns，仅用于
定位长组合路径，不能替代 STA 或宣称满足 300 MHz。面积和时序仍未验收通过。
单独乘除法单元的面积、时序也不能替代整核结果。每次实验保留 source、
参数、导出哈希、脚本和完成阶段统计。

同一 `352a51ee…` 冻结版本的六项性能测试在 RAM 延迟 20 下总 IPC 为
1.092137。无 trace `pi` 的退休、退出、完整 RAM 检查通过，但现代 Verilator
5.053 约 81.31 秒、提供的 5.020 约 198.91 秒，均不满足 30 秒；见
[双工具验证](data/lean_planes_fqv2_validation.json)。其 Verilog-2005/SYNTHESIS
导出在 51 项测试上与原 SV 周期及事件完全相同；导出的 `pi` 约 278.75 秒，
也不满足限制，见 [导出验证](data/verilog_planes_equivalence.json)。这些是具体
冻结二进制在本机的测量，后续结构修改需要重新测量。

综合命令、输入边界、严格检查及静态时序假设见
[docs/synthesis.md](../docs/synthesis.md)。ABC 延迟目标不是实测频率，面积不得
用未提供的 RAM 宏或黑盒替代片上状态后计算。
