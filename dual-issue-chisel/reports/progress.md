# 双发射 Chisel 迁移验收进度

参考为 `d134aa1` 的默认双发射 ROB32 Verilog；配置和输入 SHA-256 见 [初始输入](initial-port/v1-inputs.json)。CPU、缓存和总线均已有完整原生 Chisel 实现，未使用 Verilog CPU BlackBox。

| 官方正确性、延迟 20 | v1：19/19 |
| 六项性能、延迟 10 | v1：IPC 几何平均 1.2221711020，六项周期与参考逐项一致 |
| 六项性能、延迟 20 | v1：IPC 几何平均 1.1138460960，六项周期与参考逐项一致 |

| 高地址 | v1：116 周期、结果 0x40100 |
| 组合形式检查 | 前缀加法器、译码、ALU、分支、操作数旁路、并行选择、分发树、Cache lookup 等价 |

v1 的一条动态索引 Chisel assertion 被 firtool 1.62.0 同时输出成未受 `SYNTHESIS` 宏保护的 SVA，导致课程 Yosys 最终映射检查拒绝。v2 仅将该仿真检查改成 `stop`，官方脚本未修改，已能完整综合。v1/v2 的电路等价检查仍在运行，不能把两个版本的结果混作最终验收。

v2 映射后递归展开实际保留 2,008 个分发反相器实例（15,982 位），参考版为 2,016 个（16,008 位）；首版仅传递了模块 `keep_hierarchy`，部分实例仍可删除。初次从统计表读取的 1,160 是直接实例统计，不能与递归实例总数比较。v3 在反相器模块加 `keep=1`，完整映射后已准确恢复 2,016 个实例、16,008 位；独立六叶树也保留 20 个反相器 bank。相关语义见 [Yosys 官方实现](https://github.com/YosysHQ/yosys/blob/main/kernel/rtlil.cc)。v3 时序分析仍在运行。

v3 最终为 **484.619025083MHz、36,408.242880009μm²**。v4 同时将译码、ALU 和分支的互斥 case 数据选择显式表达为 Chisel `Mux1H`，组合等价检查通过；综合为 **491.127098321MHz、36,428.523660009μm²**。两者仍未达标。递归模块面积对照显示，前缀节点、加法器、Cache lookup 等保留模块面积与参考一致；主要额外面积来自扁平化顶层的约 531–551μm²。

v5 关闭 firtool 中间优化，测得 **485.308056872MHz / 36,474.231960009μm²**；v6 保留译码器及 RAT 边界，测得 **436.860068259MHz / 36,013.343580010μm²**。v7 只保留译码器边界，面积达到 **35,928.983700008μm²**，但频率为 **446.381865737MHz**。冻结源码、官方约束和原始测量见 [各候选归档](candidates/)。

v8 单独保留 RAT 边界，测得 **460.846084608MHz / 36,376.910460011μm²**；v9 把整个译码记录表示为互斥 opcode 的并行逻辑，测得 **491.127098321MHz / 36,324.072540009μm²**；v10 从同一指令位直接计算分派类别，测得 **485.768500949MHz / 36,074.550420013μm²**。这些候选仍未同时过线。

新版译码的全部输出已对全部 32 位指令编码证明与原 Verilog 等价，分派类别亦已对全部编码证明与原操作枚举再译码一致，包括非法编码。原始 SAT 日志与电路见 [译码等价证据](decode-equivalence/result.json)。v11 在 v10 基础上保留译码器边界，测得 **465.031789282MHz / 35,939.583360008μm²**。它们均未改队列容量、寄存边界或官方约束。

v12 让 RAT 使用未经发布门控的原始目的寄存器号进行比较；`rename_valid` / `rename_prepare` 仍控制发布及同批旁路，ROB 继续捕获原先门控后的 `rename_rd`。对两条任意 32 位指令、任意预留/发布控制及任意源寄存器输入，已 SAT 证明全部 64 项映射写使能和 4 项旁路使能与原连接一致，见 [RAT 输入等价证据](rename-input-equivalence/result.json)。该变化没有增加寄存器。v12 测得 **496.124031008MHz / 35,924.216040008μm²**。

v13 继续采用相同电路逻辑，取消译码器的额外层次保留，官方综合达到 **502.700049092MHz / 35,930.966580008μm²**，频率和面积均通过。仍保留 ROB32、原队列/Cache 规模、原时钟边界及 2ns 官方约束。

当前可编辑源码和 `rtl/student_top.sv` 对应 **v13 待最终功能复核候选**。表中的完整功能与逐拍验证记录绑定初始 v1；v13 需要独立完成全部正确性、两组 IPC、逐拍对照和默认路径综合复测后才能标记最终验收。初始版本的冻结 Chisel 源码见 `initial-port/v1-source.tar.gz`。

v13 默认交付路径已独立复测为 **502.700049092MHz / 35,930.966580008μm²**，与候选路径完全相同；当前 Scala 再生成的 RTL 与测量输入逐字节一致。新编译二进制的两组性能和高地址检查通过，十二项周期数仍与原 Verilog 一致。完整正确性和最终逐拍对照正在运行，原始记录位于 `reports/final/`，尚未标记最终验收。

默认三检查点 RAT 的完整寄存器对应已建立：252 项别名对应 764 位状态，加上 24 位输出，共 788 个等价单元全部通过归纳证明。证明保留所有合法检查点索引 0..2；未使用的编码 3 在两边都映射为 0，避免参考 Verilog 越界读的未定义行为。该证明比初始未收敛的 5 拍整体展开检查更强，配方见 `scripts/prove_rename.py`，证据见 [最终 RAT 证明](final/rat-equivalence/result.json)。

v13 最终原生二进制已通过延迟 20 的 **19/19 完整正确性**。直接从最终交付 RTL 提取的译码器已再次通过全部 32 位指令编码的等价证明，当前 Scala 生成的分派分类与 RAT 输入控制引理也均通过组合 SAT；见 [最终组合证明](final/combinational-proofs/)。完整双 CPU 正确性逐拍对照仍在运行。初始未收敛的整体 RAT 展开及 v1/v2 内部自动匹配实验已停止，由最终 RAT 归纳证明、当前 RTL 的证明和独立回归提供验收证据。

最终交付 RTL 的前缀加法、ALU、分支与操作数旁路均通过组合等价；AXI 适配器和内存仲裁器均通过 8 拍有界等价，见 [最终模块证明](final/module-proofs/results.json)。仲裁器在整机生成时已传播两缓存始终接收响应的常量，故参考侧同样固定 `s_rsp_ready=2'b11`；该集成假设在配方和结果中显式记录。最终映射后的分发树仍为 2,016 个反相器实例、16,008 位，清单见 [递归结构核对](final/synthesis/distribution-inventory.json)。最终双 CPU 两组性能对照的十二项测试均已通过并归档，周期逐项一致。

最终双 CPU 正确性逐拍对照已完成前 **14 项**，其中最长的 π 用例通过 **6,548,409 周期**，与参考完全一致；截至该项的原始日志见 [部分对照结果](final/differential/correctness-through-pi.log)。其余五项仍在运行，该部分记录不作为完整 19 项验收。

当前尚未完成目标；最终必须由同一冻结版本同时证明正确性、参考设计周期一致性、IPC、面积及 ≥500MHz。已完成检查的原始记录见 [初始验证归档](initial-port/sha256.json)，时序失败候选也明确保留。
