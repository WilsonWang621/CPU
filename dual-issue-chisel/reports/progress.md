# 双发射 Chisel 迁移验收进度

参考为 `d134aa1` 的默认双发射 ROB32 Verilog；配置和输入 SHA-256 见 [初始输入](initial-port/v1-inputs.json)。CPU、缓存和总线均已有完整原生 Chisel 实现，未使用 Verilog CPU BlackBox。

| 官方正确性、延迟 20 | v1：19/19 |
| 六项性能、延迟 10 | v1：IPC 几何平均 1.2221711020，六项周期与参考逐项一致 |
| 六项性能、延迟 20 | v1：IPC 几何平均 1.1138460960，六项周期与参考逐项一致 |

v1 的一条动态索引 Chisel assertion 被 firtool 1.62.0 同时输出成未受 `SYNTHESIS` 宏保护的 SVA，导致课程 Yosys 最终映射检查拒绝。v2 仅将该仿真检查改成 `stop`，官方脚本未修改，已能完整综合。v1/v2 的电路等价检查仍在运行，不能把两个版本的结果混作最终验收。

v2 映射后递归展开实际保留 2,008 个分发反相器实例（15,982 位），参考版为 2,016 个（16,008 位）；首版仅传递了模块 `keep_hierarchy`，部分实例仍可删除。初次从统计表读取的 1,160 是直接实例统计，不能与递归实例总数比较。v3 在反相器模块加 `keep=1`，完整映射后已准确恢复 2,016 个实例、16,008 位；独立六叶树也保留 20 个反相器 bank。相关语义见 [Yosys 官方实现](https://github.com/YosysHQ/yosys/blob/main/kernel/rtlil.cc)。v3 时序分析仍在运行。

v3 最终为 **484.619025083MHz、36,408.242880009μm²**。v4 同时将译码、ALU 和分支的互斥 case 数据选择显式表达为 Chisel `Mux1H`，组合等价检查通过；综合为 **491.127098321MHz、36,428.523660009μm²**。两者仍未达标。递归模块面积对照显示，前缀节点、加法器、Cache lookup 等保留模块面积与参考一致；主要额外面积来自扁平化顶层的约 531–551μm²。

v5 关闭 firtool 中间优化，测得 **485.308056872MHz / 36,474.231960009μm²**；v6 保留译码器及 RAT 边界，测得 **436.860068259MHz / 36,013.343580010μm²**。v7 只保留译码器边界，面积达到 **35,928.983700008μm²**，但频率为 **446.381865737MHz**。冻结源码、官方约束和原始测量见 [各候选归档](candidates/)。

v8 单独保留 RAT 边界，测得 **460.846084608MHz / 36,376.910460011μm²**；v9 把整个译码记录表示为互斥 opcode 的并行逻辑，测得 **491.127098321MHz / 36,324.072540009μm²**；v10 从同一指令位直接计算分派类别，测得 **485.768500949MHz / 36,074.550420013μm²**。这些候选仍未同时过线。

新版译码的全部输出已对全部 32 位指令编码证明与原 Verilog 等价，分派类别亦已对全部编码证明与原操作枚举再译码一致，包括非法编码。原始 SAT 日志与电路见 [译码等价证据](decode-equivalence/result.json)。v11 在 v10 基础上保留译码器边界，正在综合。它们均未改队列容量、寄存边界或官方约束。

当前可编辑源码和 `rtl/student_top.sv` 对应 **v11 待验收候选**。表中的完整功能与逐拍验证记录绑定初始 v1；这些记录不代表 v11 已完成最终验收。初始版本的冻结 Chisel 源码见 `initial-port/v1-source.tar.gz`。

当前尚未完成目标；最终必须由同一冻结版本同时证明正确性、参考设计周期一致性、IPC、面积及 ≥500MHz。已完成检查的原始记录见 [初始验证归档](initial-port/sha256.json)，时序失败候选也明确保留。
