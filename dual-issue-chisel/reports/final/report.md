# 原生双发射 Chisel 最终验收

最终交付 **v13 已通过本地 Tier3 和 ≥500 MHz 验收**。参考为迁移开始时的最新 Verilog `d134aa1`；原 Verilog、课程脚本及约束保持原样。原生 Scala/Chisel 实现覆盖完整 CPU、缓存、乘除法、仲裁器和 AXI 适配器，正常生成流程不读取或封装参考 CPU。

| 指标 | Chisel 实测 | 门槛 |
| --- | ---: | ---: |
| 官方默认路径综合频率 | **502.70004909180165 MHz** | ≥500 MHz |
| 总面积 | **35930.96658000839 μm²** | ≤36000 μm² |

配置保持 ROB32、双分派/双提交、双整数端口和独立访存端口、3×4 项 IQ、3 个分支检查点、8 个 Load 槽、16 个 Store 槽、1 KiB I-cache、2 KiB D-cache、64 B 数据缓存行、4 MSHR、16 个总线在途事务。同步复位、预准备、分支恢复及各流水级的寄存边界沿用参考设计。映射后递归核对仍有 **2016 个分发反相器实例、16008 位**。

## 相同程序的周期核对

最终原生 CPU、最终双 CPU 对照和原 Verilog 参考的 19 项正确性周期逐项相同。性能的动态指令数、周期和 IPC 也逐项相同：

| 用例 | 动态指令数 | 延迟 10 周期 | 延迟 20 周期 |
| --- | ---: | ---: | ---: |
| median | 6961 | 6615 | 7233 |
| multiply | 21722 | 16794 | 17029 |
| qsort | 139900 | 127719 | 134993 |
| rsort | 195719 | 120418 | 134501 |
| towers | 5278 | 4804 | 5255 |
| vvadd | 4524 | 3614 | 4405 |

对照器让两个完整 CPU 接收相同 AXI 返回，逐拍检查 AR/AW/W 有效、有效请求的地址/数据/字节掩码，以及 R/B 接收时刻；无效请求的负载不参与比较。该回归涵盖上述程序和内存延迟，不等于整机全状态形式等价证明。

## 形式验证及版本绑定

- 从最终交付 RTL 直接提取的译码器、前缀加法器、ALU、分支和操作数旁路均通过组合等价证明。译码穷尽全部 32 位编码，包含非法编码；分派类别和 RAT 输入控制分别用当前 Scala 生成的引理证明。
- 默认 3 检查点 RAT 的 764 位状态与 24 位输出，共 788 个等价单元全部通过归纳证明。合法检查点索引 0..2 不变，未用编码 3 在两边均映射为 0，避免参考越界读的未定义行为。
- 最终 AXI 适配器及仲裁器通过 8 拍有界等价。仲裁器按实际整机连接固定两缓存响应接收就绪为 1；该假设显式保存在证明配方。独立仲裁器的任意输入 8 拍证明及 MDU、RAT、前端、D-cache 独立模型回归见[初始归档](../initial-port/)。

最终生成 RTL SHA-256：`9ea7ed6c12f131da8d045ecae9484aea52fe75d4bf8e96e53a52e0feaf05e977`。当前可编辑 Scala 再生成结果与该交付文件逐字节一致；默认入口重新综合与冻结 v13 候选的面积、频率完全相同。源码清单和仿真二进制哈希见 [final-input-receipt.json](final-input-receipt.json) 与 [simulator-receipt.json](simulator-receipt.json)，冻结源码见 [v13/source.tar.gz](../candidates/v13/source.tar.gz)。

综合使用官方 ASAP7 RVT TT、2.0 ns 时钟、INVx1 驱动、5 fF 输出负载、0.2 ns 输入/输出延迟、0.05 ns 时钟不确定度。面积包含缓存的触发器实现，SRAM 面积为 0。时序为理想时钟、无布线寄生的课程综合/STA 估计；精确配方、库哈希和原始报告见 [synthesis/](synthesis/)。
