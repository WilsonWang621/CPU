# Single issue Chisel CPU

独立单发射乱序 RV32IM 工程，根目录的 v42 双发射实现已经封存。CPU 源码按译码/执行、乘除法、缓存/前端、总线、乱序核心分模块。

验收固定使用课程原样 `scripts/synth.py`、ASAP7 RVT TT 及课程默认时序约束；性能测试内存延迟 20、上限 30,000,000 周期。总面积包括 SRAM。

| 实现阶段 | 必须保留的门槛 | 频率目标 | 当前状态 |
|---|---|---:|---|
| 1 | 19/19 正确性，面积 ≤18,000 μm²，IPC ≥0.845 | >300 MHz | 实现和优化中，未达标 |
| 2 | 阶段 1 全部门槛 | ≥400 MHz | 阶段 1 验收后启动 |
| 3 | 阶段 1 全部门槛 | ≥500 MHz | 阶段 2 记录后尝试 |

每个实验冻结生成 RTL、参数、源码哈希，记录六项性能细目、几何平均、面积、默认综合频率及关键路径。每阶段先记录前后参数对照，再提交验证过的模块实现。400/500 MHz 是待验证目标；只有实测同时满足正确性、面积和 IPC 才标记达标。

```sh
make generate
make build
make test
make perf
make synth
```

生成器使用 Chisel 6.5.0 / Scala 2.13.12。仿真与综合均读取已生成的 `rtl/student_top.sv`，不需要修改课程评测流程。

首版记录位于 `reports/stage1/base-v1/`：19 项正确性通过；默认综合 48.471 MHz，面积 13,669.664 μm²，IPC 0.5557，尚未达到 Tier2。优化优先项是访存吞吐和完成/恢复控制扇出。

最新完整验证的 v24：19/19 正确性、六项性能通过，IPC **0.84634**，默认综合 **115.15 MHz / 18,258.86 μm²**。它已达到 IPC 门槛，频率和面积仍未通过，因此阶段 1 尚未验收，阶段 2/3 尚未启动。

优化前后和参数明细见 [阶段 1 对照](reports/stage1/comparison.md) 与 [优化说明](reports/stage1/optimization-notes.md)。`rtl/` 暂时保留首版；实验验收使用各目录内冻结的 RTL、源码哈希和原始日志。
